## Chromosome-Level Effects of MSL Knockdown in Drosophila S2 RNA-seq Data
This project compares the effects of msl2 and mof RNAi on gene expression in Drosophila S2 cells focusing on difference between X and autosomal genes.

## Setup
1. Install R and R studio
2. Download or clone this repository
3. Open the ".Rproj" file in R studio
4. Restore the required package versions by running "renv::restore()"

## Rerun
Open "task-5.Rmd" and click "Knit" to generate the HTML report. The report includes exploratory plots, Deseq comparisons, chromosome-level gene summaries, explanations, interpretation of the results.
